# PIP2 A2/Movers ESL Exercise Design Guide

## Purpose
Use this guide as the default specification for creating ESL lesson materials, exercises, answer keys, and exercise descriptions for independent e-learning at A2 / Cambridge Movers level.

The guide is lesson-neutral. Do not copy lesson-specific topics, names, stories, or answers from previous materials unless they are supplied in the current task.

---

## 1. Target Level and Language

### MUST
- Write for A2 / Cambridge Movers learners unless another level is requested.
- Use short, clear, natural English.
- Prefer familiar vocabulary and concrete meanings.
- Keep sentence structures easy to process independently.
- Make context strong enough to support understanding.
- Use slightly challenging vocabulary only when it is useful and deliberately introduced.

### SHOULD
- Prefer natural English over mechanically simplified English.
- Use common connectors and storytelling phrases learners can reuse.
- Keep instructions concise and consistent.

### AVOID
- Unnecessarily formal, abstract, idiomatic, or literary language.
- Long sentences with several clauses.
- Simplifications that sound unnatural to a native speaker.
- Difficult structures when a simpler natural structure expresses the same meaning.

---

## 2. E-Learning Context

Materials are designed primarily for self-study.

### MUST
- Make tasks possible to complete independently.
- Give clear instructions and, for closed-ended tasks, a clear answer key.
- Avoid pair work, group work, or “discuss with a partner” unless explicitly requested.
- Keep interaction patterns suitable for an e-learning screen.

### SHOULD
- Prefer controlled and close-ended practice before freer production.
- Limit unnecessary reading load in speaking and writing practice.
- Use visual support where it meaningfully reduces language load.

---

## 3. Recommended Lesson Flow

A lesson may use the following sequence when appropriate:

1. Topic introduction
2. PTV / pre-teach vocabulary
3. Main input: reading or listening
4. Gist
5. Main ideas
6. General comprehension / sequence
7. Details
8. Specific information
9. Useful language / language noticing
10. Controlled speaking or writing practice
11. Guided production
12. Freer production or final task

Not every lesson needs every stage. Choose stages based on the learning objective.

### Key principle
Each stage should have a different purpose. Do not repeatedly test the same information in slightly different formats.

---

## 4. Exercise Description Style

Use concise instructional-design descriptions.

### Preferred pattern
“Students [skill/focus]. They [what they do]. The [items/options/text] should [important design requirement].”

### Example template
“Students read for specific information. They read the text and complete each sentence with the exact word from the reading. Each sentence should provide enough context to eliminate any other plausible answer. The example(s) can be kept or replaced.”

### Descriptions SHOULD state
- The skill or language focus.
- The student action.
- What the content focuses on.
- Important item-writing constraints.

### AVOID
- Vague descriptions such as “Students practice reading.”
- Long explanations of the lesson content.
- Including answer keys or lesson-specific information in the description unless requested.

---

## 5. Topic Introduction

Purpose: activate interest and relevant background knowledge without giving away the input text.

### SHOULD
- Be quick and low-load.
- Use familiar language.
- Encourage a simple prediction, choice, categorization, or observation.
- Avoid revealing the main surprise, answer, or key events of the reading/listening.

For self-study, open prediction questions may be used when there is no required correct answer, but core practice should remain checkable.

---

## 6. PTV / Pre-Teach Vocabulary

Purpose: introduce difficult but necessary vocabulary before the main input.

### MUST
- Use simple, contextual meaning clues.
- Use contexts different from the main reading/listening when possible.
- Avoid making the upcoming topic too obvious.
- Make each clue point clearly to one target word or phrase.

### Preferred clue style
“You do this again and again before the test.”
→ target vocabulary item

### Clues SHOULD
- Be A2-friendly.
- Be concrete and contextual rather than dictionary-like.
- Be long enough to make the intended meaning clear.
- Avoid using the target word itself.

### Multiple-choice PTV
- Keep options structurally comparable.
- Where possible, use the same word count within an item or option set.
- Do not let students answer simply because one option has a different grammatical form or length.

---

## 7. Reading Text Design

Reading texts should support both comprehension and later exercise construction.

### SHOULD
- Have a clear overall topic.
- Have identifiable paragraph/section main ideas.
- Include a clear sequence where appropriate.
- Include distinct supporting details.
- Include enough contrasting or competing information to build plausible distractors later.
- Maintain a consistent A2/Movers language level.

### AVOID
- Packing too many difficult words into one paragraph.
- Repeating the same idea in several ways solely to increase length.
- Adding facts only to make exercises harder if they reduce clarity.

---

## 8. Reading Text Descriptions

A reading description should identify:
- Text type.
- General topic.
- Main content areas or progression.
- Approximate word count when required.

### Template
“The reading text is a/an [text type] about [general topic]. It explains/describes [main content progression]. (word limit ~ X–Y words)”

Do not summarize every event or reveal the main surprise.

---

## 9. Reading for Gist

Purpose: identify what the whole text is mainly about.

### Preferred format
“What is the text mainly about?”

Use a small set of options.

### Correct answer
- Must describe the text as a whole.

### Distractors
- Should be plausible.
- May describe a real detail or one section of the text.
- May be closely related to the topic.
- Must not describe the whole text accurately.

### Description template
“Students read for gist. They read the text quickly and choose the option that best describes what the whole text is about. The incorrect options should include ideas related to the text but should not describe its main idea.”

---

## 10. Reading for Main Ideas

Purpose: identify the central idea of major sections or paragraphs.

### Suitable formats
- Match sections to main ideas.
- Choose a heading for each section.
- Select the best summary for each paragraph.

### MUST
- Test larger ideas, not small factual details.
- Keep main-idea statements broader than specific-information questions.

Remember:
- Gist = whole text.
- Main ideas = major sections.
- Details/specific information = individual facts.

---

## 11. General Comprehension / Sequencing

For narrative or event-based texts, sequencing is useful.

### SHOULD
- Use meaningful events from across the text.
- Require understanding of the story/event order.
- Avoid simply copying consecutive source sentences.
- Keep each event statement short and clear.

---

## 12. Reading for Details

Purpose: check understanding of supporting information.

### SHOULD
- Ask about meaningful details rather than trivial wording.
- Use plausible distractors.
- Paraphrase where appropriate so the task checks comprehension rather than visual matching.
- Avoid repeating details already heavily tested in earlier exercises.

---

## 13. Reading for Specific Information: Exact-Word Gap Fill

Purpose: scan the text and retrieve precise information.

### MUST
- Require the exact word from the reading when specified.
- Have only one defensible answer.
- Give enough context to eliminate every other plausible word from the text.
- Keep grammar around the blank correct for the intended answer.

### Strong item design
Use competing details from the source so learners must distinguish information, not merely search for a familiar word.

Possible contrast types:
- one time period vs. another time period
- one place vs. another place
- an earlier state vs. a later state
- an action vs. its opposite
- one role/category vs. another

### Description template
“Students read for specific information. They read the text and complete each sentence with the exact word from the reading. Each sentence should provide enough context to eliminate any other plausible answer. The example(s) can be kept or replaced.”

---

## 14. Distractor Design

Distractors must be plausible but clearly incorrect after careful reading/listening.

### GOOD distractors
- Are mentioned elsewhere in the source.
- Belong to the same semantic category as the answer.
- Refer to another event, person, place, time, or detail.
- Require students to understand which information belongs where.

### BAD distractors
- Are obviously unrelated.
- Are grammatically impossible.
- Differ so much in form or length that the answer is obvious.
- Could also correctly answer the question.
- Let students answer without understanding the source.

### Core rule
A distractor should create a meaningful choice, not a trick.

---

## 15. Non-Interchangeable Options

This is a high-priority quality rule.

When several answers appear in one option bank, every blank must have one clearly correct choice.

### MUST
- Check every option against every blank.
- Use grammatical and semantic clues to prevent swapping.
- Rewrite the sentence context if two options can both fit naturally.

### SHOULD
- Mix functions when useful: opening, cause/result, reaction, duration, ending, etc.
- Avoid putting several nearly identical sequencing expressions in one bank unless the sentence context clearly separates them.

### QA test
For each blank, mentally insert every other option. If another option remains natural and preserves the intended meaning, revise the item.

---

## 16. Listening Text Design

Listening scripts should use:
- Natural conversational language.
- Clear speaker turns.
- A2/Movers-friendly sentence length.
- Enough context for learners to infer meaning.
- Useful repeated structures without sounding repetitive.

When multiple listening exercises use the same audio, each exercise should focus on different information.

---

## 17. Listening Text Descriptions

### Template
“The listening text is/includes [text type] about [general topic]. The speakers talk about [main content areas]. (word limit ~ X–Y words / ~ X–Y words per conversation)”

Do not give a line-by-line summary.

---

## 18. Listening for Specific Information

### SHOULD
- Use short answers or short options.
- Keep answer choices concise, often 1–2 words when appropriate.
- Test details not already used as the main focus of a previous exercise.
- Make distractors plausible and comparable.

Students should need to listen for meaning rather than rely on option length or grammar alone.

---

## 19. Speaking Practice

For self-study speaking tasks:

### MUST
- Avoid required pair work unless requested.
- Give enough structure for the learner to respond independently.
- Focus on the useful language from the lesson.

### Suitable controlled formats
- Choose the best reaction, then say it aloud.
- Complete a short response and record/say it.
- Select a prompt and produce one short response.
- Build a mini-dialogue from provided chunks.

When using reaction phrases, make the context strong enough that the choices are non-interchangeable.

---

## 20. Dialogue Exercises

Dialogue completion/reordering should test natural conversational flow.

### MUST
- Give enough context before and after a blank.
- Make reaction sentences non-interchangeable.
- Ensure each response matches the speaker’s emotion, question, or information.

### Description template
“Students practice forming dialogues. They read a dialogue about [general situation] and [complete/reorder] the reaction sentences. The context should make the position of each sentence clear. The example(s) can be kept or replaced.”

---

## 21. Writing Introduction / Language Noticing

Purpose: help learners notice how a short text is organized before they write.

Students may identify language used to:
- Begin a story.
- Set the scene.
- Connect events.
- Introduce a problem.
- Show cause/result.
- Show contrast.
- Express a reaction or surprise.
- Move the story forward.
- End a story.

Keep the task controlled and independently checkable.

---

## 22. Useful Language for Story Writing

“Useful language” should mean natural chunks students can reuse when telling their own story.

### Useful functions
- Opening.
- Sequencing.
- Setting the scene.
- Cause/result.
- Reaction/surprise.
- Positive or negative outcome.
- Continuation.
- Ending.

### Example types of reusable phrases
- One day, ...
- It began when ...
- It all started when ...
- First, ...
- Then, ...
- After that, ...
- After some time, ...
- To his/her surprise, ...
- Luckily, ...
- Sadly, ...
- Finally, ...
- In the end, ...
- From then on, ...

Use only phrases that fit the learners’ level and sound natural in the specific sentence.

### IMPORTANT
Do not make a “useful language” exercise only a list of time expressions. Include different storytelling functions where possible.

---

## 23. Comic-Based Writing Practice

A visual story can be used to reduce reading load and introduce narrative structure.

### Recommended layout
For a four-frame comic:
- 2 short sentences or target blanks per frame.
- 8 targets total when appropriate.

### SHOULD
- Make the sentences closely match what the learner can see.
- Use the comic to support understanding of the target phrases.
- Use reusable storytelling language.
- Keep option banks non-interchangeable.

If options are grouped across multiple frames, verify that an option intended for one frame cannot naturally fit a blank in another frame in the same group.

---

## 24. Sentence Unscrambling for Writing

Purpose: practice sentence formation while building a short coherent story.

### Instruction template
“Put the words and phrases in the correct order to make a short story.”

### MUST
- Keep the scrambled chunks logical.
- Make only one natural sentence order where possible.
- Use A2/Movers grammar.
- Ensure the finished sentences form one coherent story.

### SHOULD
- Include a useful storytelling phrase in each sentence when the objective is narrative writing.
- Scramble meaningful chunks rather than every individual word when word-by-word scrambling creates unnecessary difficulty.
- Keep the story short enough that the task remains writing practice rather than a long reading task.

---

## 25. Writing Practice Progression

A useful progression is:

1. Notice useful language.
2. Choose or complete useful phrases.
3. Reorder/unscramble sentences.
4. Complete a guided story.
5. Write a short story with prompts or pictures.
6. Write more independently.

Move from recognition to controlled production before asking learners to create a full text.

---

## 26. Naturalness Rule

Every item must satisfy all three:

1. Grammatically correct.
2. Appropriate for A2/Movers.
3. Natural in context.

Do not keep an awkward sentence merely because it creates a convenient blank.

If a sequence of connectors sounds mechanical or unnatural, revise the sentence or use a different storytelling function.

---

## 27. Avoid Redundant Testing

When several exercises use the same input:

- Gist should test the whole-text idea.
- Main ideas should test sections.
- General comprehension may test sequence or broad understanding.
- Details should test supporting information.
- Specific information should test precise facts.
- Useful-language work should focus on transferable language.
- Writing/speaking practice should apply the language rather than retest the same facts.

Do not turn every exercise into another version of the same comprehension question.

---

## 28. Source-Text Planning for Exercise Writers

When creating a new reading/listening from scratch, plan for later exercises.

Include:
- One clear overall idea.
- Distinct section/paragraph ideas.
- A manageable number of concrete details.
- Clear sequence markers when relevant.
- Some naturally contrasting details that can later support good distractors.
- Useful language that can be recycled in productive practice.

Do not distort the text merely to manufacture distractors.

---

## 29. Answer-Key Standards

### MUST
- Check every answer against the exact item wording.
- Verify there is only one correct answer.
- For exact-word tasks, match the source spelling/form exactly.
- For option-bank tasks, test all options in all blanks.
- Keep answer keys easy for content developers to scan.

---

## 30. Final QA Checklist

Before delivering an exercise set, check:

### Level
- Is the language genuinely A2/Movers-friendly?
- Are difficult words necessary or pre-taught?
- Are sentences short enough?

### Naturalness
- Does every sentence sound natural?
- Do connectors and phrases fit the context?
- Has simplification made anything awkward?

### Task objective
- Does the exercise actually test the named skill?
- Is it different from the previous exercise?
- Is the learner doing the intended cognitive work?

### Answers
- Is there exactly one correct answer per closed-ended item?
- For exact-word tasks, is the answer exactly in the source?
- Can any alternative reasonably fit?

### Distractors
- Are they plausible?
- Are they comparable?
- Do they require understanding rather than guessing?
- Are they clearly wrong after checking the source?

### Option banks
- Are options non-interchangeable?
- Have all options been tested against all blanks?
- Are forms/lengths reasonably balanced?

### E-learning
- Can a learner complete the task alone?
- Are instructions clear without teacher explanation?
- Is the reading load appropriate for the skill being practiced?

### Progression
- Does the lesson move from input/recognition toward controlled and then guided production?
- Are later tasks recycling useful language rather than merely repeating comprehension?

---

## 31. Core Principle

Students should need to understand meaning to get the answer.

Do not let them succeed only by:
- recognizing a repeated word,
- matching option length,
- spotting an obvious grammatical mismatch,
- copying a sentence without understanding it,
- or eliminating unrealistic distractors.

Aim for:
**one clearly correct answer + plausible alternatives + enough context to eliminate the alternatives + natural A2/Movers English.**
